How the roll stays fair

Random push. The launch speed and the starting name both come from crypto.getRandomValues, the browser's cryptographic random source. Nothing about the result is chosen in advance.

Real physics. The reel is simulated at 480 steps per second with air drag and rolling friction, and nothing nudges it toward a name. It can stop anywhere. Once it is at rest, the line in the middle picks whichever name it is touching. The simulation uses a fixed time step, so a slow or busy computer changes how smooth it looks but never where it stops.

No order bias. Entries are shuffled with a crypto-seeded Fisher–Yates shuffle before every roll and the reel starts on a uniformly random name, so alphabetical order, join order or first letter cannot tilt the odds. Each person gets exactly one slot, no matter how many times they type the keyword. With subscriber luck on, subscribers get a second slot, placed randomly but never right next to their first one unless there's no other way.
